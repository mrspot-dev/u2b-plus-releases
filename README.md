# U2B+

<img src="assets/u2b-plus-icon.png" width="96" height="96" alt="U2B+ Icon">

Hier liegen die Installationsdateien von U2B+ für Windows 11. Den Quellcode gibt es hier nicht.

U2B+ ist ein privates, nicht kommerzielles Projekt für einen kleinen Freundeskreis. Es gibt keinen Support und nichts zu kaufen.

## Installieren

Rechts unter „Releases“ die neueste Version öffnen und die Datei `U2B-Plus-…-setup.exe` speichern. Die Installation braucht keine Adminrechte.

U2B+ ist nicht signiert, deshalb zeigt Windows beim Start der Installation eine Warnung. Ein Klick auf „Weitere Informationen“ bringt den Knopf „Trotzdem ausführen“.

Neue Versionen holt sich U2B+ danach von selbst.
