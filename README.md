# U2B+

<img src="assets/u2b-plus-icon.png" width="96" height="96" alt="U2B+ icon">

Windows installer and update files for U2B+. The source code is not published here.

## Installation

Open the latest version under Releases and run `U2B-Plus-…-setup.exe`. No administrator rights are required.

The installer is not code-signed, so Windows may show a SmartScreen warning. Select "More info", then "Run anyway".

U2B+ installs new versions on its own.
